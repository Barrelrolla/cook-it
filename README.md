# Garndish

**Garndish** is a modern recipe discovery and sharing platform built to make finding, saving, and exploring recipes simple and enjoyable.

Users can discover recipes by category, cuisine, ingredients, and dietary preferences, save their favorites, and share their own recipes.

## Tech Stack

- **Next.js** · React · TypeScript
- **Tailwind CSS**
- **Drizzle ORM** · PostgreSQL
- **Better Auth**
- **next-intl**
- **Vercel**

## Highlights

- Recipe discovery with filtering and pagination
- Ingredient and dietary preference support
- User-created recipes
- Save and like functionality
- Responsive, accessible UI
- Internationalization support
